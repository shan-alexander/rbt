## What each run does

| Run | Bronze | Bronze register | Transform | Output root |
|-----|--------|-----------------|-----------|-------------|
| Arrow+spill | `lz_stock_bars` IPC hive | **force re-spill** | serial mega TA | `lake/compare_arrow_output/` |
| Parquet | `lz_stock_bars_parquet` | DF **listing** (no spill) | serial mega TA | `lake/compare_parquet_output/` |
| Parquet+par | same Parquet hive | DF listing | **RBT-C** partition WorkUnits | `lake/compare_parquet_parallel_output/` |

## Interpretation

- **Arrow+spill** pays IPC decode + spill encode every forced run.
- **Parquet** avoids spill; registration is listing — usually the largest win on bronze→stg.
- **Parquet+par** adds L2 concurrency on indicators; wins when TA/I-O per symbol is heavy enough to amortize WorkUnit overhead (on this demo, often close to serial Parquet).
- `total_rows` is the engine sum across models (stg + tf [+ units] + obt), not unique bar count.

## Reproduce

```bash
cargo run -p full-e2e-rbt-example --release -- \
  -p examples/full_e2e_rbt_example compare -j 8
```
